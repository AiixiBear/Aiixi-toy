Set a Device PIN (optional)

Setting a PIN locks the OTP list and settings behind it. The PIN is sent to the device only when you set or enter it, and is never stored in the browser. The PIN can only use the digits 7 and 8 (4-12 digits): on the device, button B enters 7 and button A enters 8.

Supports otpauth://totp/ URIs from authenticator apps (Google Authenticator, Authy, etc.)
