Set a Device PIN (optional)

Setting a PIN locks the OTP list and settings behind it; the WebUI then asks for the PIN before it opens. The PIN is sent to the device only when you set or enter it, and is never stored in the browser. The PIN can only use the digits 7 and 8 (4-12 digits): on the device, button B enters 7 and button A enters 8.

      Home screen

      Connections

      Bluetooth

      Bluetooth LE HID keyboard for typing OTP codes and the media remote. Turning it off disconnects the paired host and stops advertising; turning it back on restarts advertising without a reboot.

      WebUI Background

      Keep WiFi and the WebUI running while you use other apps on the device, so this page stays reachable without opening WiFi Setup. Works in both AP and STA mode. Off by default: keeping the radio on uses more battery. You can also toggle it on the device, in WiFi Setup with button A.
